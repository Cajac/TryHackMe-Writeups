# AI Fundamentals Module

```text
Type: Module
Difficulty: Medium
Description:
Learn the core concepts of AI and ML, and how they apply to the cybersecurity landscape.

This module introduces learners to the foundational concepts of artificial intelligence and 
machine learning, establishing the mental models needed before diving into security topics. 
Rooms cover AI/ML threat categories, how models consume and process data, prompt engineering 
basics, and how AI can be used to augment existing roles using digital forensics as an 
example with a companion challenge to close off.
```
