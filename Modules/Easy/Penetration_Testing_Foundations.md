# Penetration Testing Foundations Module

```text
Type: Module
Difficulty: Easy
Description:
Learn core penetration testing concepts through two guided engagements and the frameworks that 
shape every real-world test.

This module drops you straight into the action with two guided engagements: one against a web 
application and one against a vulnerable machine. You’ll walk through each attack from 
reconnaissance to exploitation, see how the cyber kill chain structures attacker thinking, 
and meet the industry-standard frameworks that shape professional engagements. By the end, 
you’ll have the working mental model every penetration test relies on.
```
